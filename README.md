# Raíces de México

Sitio web informativo sobre las tradiciones más significativas de México.

Proyecto de la materia **Multimedia y Páginas Web**, Preparatoria Mante.

## Secciones del sitio

| Página | Contenido |
| --- | --- |
| `index.html` | Portada: menú del sitio, objetivo e imagen principal |
| `fiestas.html` | Día de Muertos, Virgen de Guadalupe, Posadas, Independencia, Carnaval y Guelaguetza |
| `musica.html` | Mariachi, sones regionales y danzas tradicionales |
| `artesanias.html` | Alebrijes, textiles, barro y talavera |
| `costumbres.html` | Celebraciones y reuniones familiares |
| `recursos.html` | Datos curiosos, fuentes y créditos de fotos |

## Objetivo del sitio

Mostrar cómo las costumbres y celebraciones forman parte de la identidad mexicana, compartir información sobre su historia y explicar por qué siguen siendo importantes en distintas comunidades del país.

## Ver el sitio

Abre `index.html` en el navegador, o activa GitHub Pages en **Settings > Pages** (rama `main`, carpeta `/root`).

Las fotografías se toman de Wikimedia Commons con licencias libres; los créditos aparecen debajo de cada imagen.
